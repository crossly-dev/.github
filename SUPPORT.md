# Getting help

- **Using Crossly** (connecting marketplaces, crossposting, orders): the [guides](https://crossly.net/guides).
- **Building on the API**: the [docs](https://crossly.net/docs) and the OpenAPI specs for the [seller](https://crossly.net/openapi/seller.json) and [buyer](https://crossly.net/openapi/buyer.json) APIs.
- **A bug in an SDK, the CLI, MCP or another tool here**: open an issue in that repository, with the version and the smallest example that shows it.
- **Is something down?** Check [status](https://crossly.net/status).
