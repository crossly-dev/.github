### Build on Crossly

Two APIs, one account. The **seller API** runs a store: inventory, listings, crossposting, orders and automations. The **buyer API** is for shoppers: cart, orders, wishlists, offers and cashback.

| | Seller | Buyer |
|---|---|---|
| **TypeScript SDK** | [crossly-sdk](https://github.com/crossly-dev/crossly-sdk) | [crossly-buyer-sdk](https://github.com/crossly-dev/crossly-buyer-sdk) |
| **CLI** | [crossly-cli](https://github.com/crossly-dev/crossly-cli) | [crossly-buyer-cli](https://github.com/crossly-dev/crossly-buyer-cli) |
| **AI agents (MCP)** | [crossly-mcp](https://github.com/crossly-dev/crossly-mcp) | [crossly-buyer-mcp](https://github.com/crossly-dev/crossly-buyer-mcp) |

### Automations

- [**crossly-automations**](https://github.com/crossly-dev/crossly-automations): community recipes for sharing, price drops, relisting and post-sale messages across every marketplace. Drop-in JSON.
- [**crossly-recipes**](https://github.com/crossly-dev/crossly-recipes): ready-to-import recipes, validated against the live catalog.
- [**crossly-action**](https://github.com/crossly-dev/crossly-action): run Crossly from a GitHub workflow. Publish on merge, export nightly, check status.

### Your storefront, anywhere

- [**crossly-embed**](https://github.com/crossly-dev/crossly-embed): catalog and checkout as custom elements for any website. One script tag, no build step.
- [**crossly-wordpress**](https://github.com/crossly-dev/crossly-wordpress): your listings as a WordPress block or shortcode.
- [**crossly-buyer-tools**](https://github.com/crossly-dev/crossly-buyer-tools): reference tools on the buyer API, including restock and price monitors, catalogue sync and a deal scanner.

### Tools

- [**crossly-postman**](https://github.com/crossly-dev/crossly-postman): Postman collections for both APIs, auth pre-wired.
- [**crossly-releases**](https://github.com/crossly-dev/crossly-releases): desktop app installers and the browser extension.
