# Contributing

Thanks for helping. A few things make a contribution land quickly:

- **Generated SDKs** (`crossly-python`, `crossly-go` and the other language repos) are generated from the OpenAPI specs. Please open an issue describing the problem rather than a pull request against generated code, which the next release would overwrite.
- **Recipes** (`crossly-automations`, `crossly-recipes`): one recipe per pull request, valid against the schema in the repo, with a short note on what it does and which marketplaces it covers.
- **Everything else**: open an issue first for anything bigger than a small fix, so we can agree on the approach before you spend time on it.

Keep pull requests focused, say how you tested the change, and never include API keys, tokens or cookies in code, issues or logs.
